# 附录 · 心象对决

> 游戏里的战斗叫「心象对决」。敌人是某种生存状态的化身，打不死，只能被理解。下面是八场对决的全部台词，
> 按指令分组；同一个指令多次使用，回应会变化。「声势」是敌人的气势条，「心绪」是队伍的状态，心绪耗尽就只能先退开。

## 闲言史莱姆

- 地点：第二章 · 林中路
- 关联手记：闲言
- 解法：追问。闲言说不出第一个说这话的人，一问来源它就瘪下去。认真倾听反而喂大了它。

**登场**

> 闲言史莱姆冒了出来！
> 史莱姆：听说……听说……

**指令与回应**

- **追问**
  - （第1次）你看着史莱姆，像是在问：谁说的？ / 史莱姆：大家……大家都这么说…… / 史莱姆：大家是……是…… / 史莱姆瘪下去一大块！
  - （第2次）你还在等它回答。 / 史莱姆：是……隔壁的……隔壁听说的…… / 它说不出第一个说这话的人。 / 史莱姆又瘪下去一块！
  - （第3次）史莱姆：别、别问了……大家都这么说还不够吗…… / 史莱姆越来越小了。
- **倾听**
  - 你认真听它说话。 / 史莱姆：听说魔王吃人脸！听说魔王有三只眼！听说…… / 你听得越认真，它说得越起劲。 / 史莱姆胀大了一圈。
- **沉默**
  - 你一句话也不说。 / 史莱姆：……听说……喂，你听见没有？……听说…… / 没人接话，它自己说着说着就没了劲。 / 史莱姆瘪下去一点。
- **等待**
  - 你等着。 / 史莱姆：听说……听说…… / 它说个不停。等下去也不会有第一个说话的人出现。
- **动手**
  - 你挥了一下锤子。 / 锤子穿过史莱姆，像穿过一团雾。 / 史莱姆：打人啦！听说有人打人啦！ / 史莱姆胀大了！
- **克洛伊·移位**
  - 克洛伊：以太，移…… / 克洛伊：……我忘了，这里没有以太。
- **罐头·分析**
  - 罐头：分析中。 / 罐头：它是由转述组成的。每一次转述都没有来源。 / 罐头：建议询问来源。
- **宝物（其他）**
  - 你把宝物拿出来给它看。 / 史莱姆：听说那是宝物！听说很值钱！大家都这么说！ / 它根本没在看。

**敌方行动**

- 史莱姆：听说你们也要去找魔王？大家都说你们会被吃掉！
- 史莱姆：听说那个不说话的是个哑巴！大家都这么说！
- 史莱姆嘀嘀咕咕，吵得人头疼。

**胜利**

> 史莱姆说不出第一个说这话的人。
> 它越说越小，最后变成了一句谁也不记得的话，散了。

## 怕之狼

- 地点：第二章 · 林中路
- 关联手记：怕
- 解法：动手，正面迎上去；或者举起伊斯特的灯。怕总是怕某个确定的东西，看清了，它就只是一堆别人的字。

**登场**

> 怕之狼挡住了去路！
> 它的毛是一行一行的字：魔王，吃人，北边，别去。

**指令与回应**

- **追问**
  - 你盯着狼，像在问：你从哪儿来？ / 狼：从……北边……从魔王那边…… / 它毛上的字在发抖。
- **倾听**
  - 狼低吼着。你仔细听，吼声里是很多人的声音。 / 别去。危险。听说有人没回来。 / 全是别人的害怕。
- **沉默**
  - 你沉默着。狼一步一步逼近。 / 沉默对怕没什么用。它从一个确定的方向来，正朝你们走过来。
- **等待**
  - 你等着。狼也等着。 / 它在那儿，它还会在那儿。怕不会因为等待自己散掉。
- **动手**
  - （第1次）你往前迈了一步，正面看着它。 / 狼毛上的字一行一行清楚起来：据说，好像，有人讲。 / 看清楚了，它就只是一堆字。
  - （第2次）你又往前走了一步。 / 狼往后退了。它比刚才小了一圈。
- **克洛伊·移位**
  - 克洛伊：以太，移…… / 克洛伊：……没有以太。那、那本小姐就站在这儿！不跑！
- **罐头·分析**
  - 罐头：它有一个明确的方向，一个明确的对象。 / 罐头：这是怕。怕总是怕某个东西。东西是可以看清的。 / 罐头：建议正面看它。
- **宝物（其他）**
  - 你拿出宝物。狼龇着牙，毫不在意。
- **宝物·伊斯特的灯**
  - 你举起伊斯特的灯。 / 灯光照在狼身上，毛上的字一个一个显出来，又一个一个褪了色。

**敌方行动**

- 狼扑了过来！
- 狼：别去……别去……大家都说会死……
- 狼的红眼睛盯着克洛伊。 / 克洛伊的腿在发抖。

**胜利**

> 狼毛上的字一行一行散开，落在地上，变成了枯叶。
> ……原来它这么小。

## 好奇蝙蝠

- 地点：第三章 · 去钟港的路上
- 关联手记：好奇
- 解法：等待。别追它，站住，看一朵花看很久。好奇从不在任何东西上停留。

**登场**

> 好奇蝙蝠扑棱棱地飞来了！
> 蝙蝠：新的！新的！

**指令与回应**

- **追问**
  - 你想问它在找什么。 / 蝙蝠：找新的！找新的！ / 话没说完，它已经飞到下一棵树上了。
- **倾听**
  - 蝙蝠：那边有花！那边有云！那边有一只没见过的虫子！ / 它说的每样东西，它都只看了一眼。
- **沉默**
  - 你不说话。蝙蝠根本没注意到。
- **等待**
  - （第1次）你没有追它。你站住，看着路边一朵小小的白花。 / 你看了很久。花瓣边上有一点点黄。 / 蝙蝠：……你在看什么？那有什么新的？ / 它飞下来，落在你旁边，也去看那朵花。
  - （第2次）你还在看那朵花。风吹过，花晃了晃。 / 蝙蝠：……它刚才晃了一下。 / 蝙蝠的眼珠转得慢了。
  - （第3次）蝙蝠：……原来一朵花能看这么久。 / 蝙蝠打了个哈欠，眼睛闭上了。
- **动手**
  - 你冲上去追它。 / 蝙蝠：好玩！好玩！新游戏！ / 它飞得更快了。
- **克洛伊·移位**
  - 克洛伊：以太，移位！ / 克洛伊一眨眼出现在蝙蝠旁边。 / 蝙蝠：哇！新的！会闪现的人！再来一次！ / 克洛伊：本小姐不是给你表演的！
- **罐头·分析**
  - 罐头：它从不停在任何一样东西上。 / 罐头：它不缺新东西。建议给它一样可以看很久的东西。
- **宝物（其他）**
  - 你把宝物举起来给它看。 / 蝙蝠：哇！新的！ / 它看了一眼，就丢开了。

**敌方行动**

- 蝙蝠在你们头顶转圈：新的！新的！新的！
- 蝙蝠叼走了克洛伊的丝带，看了一眼，又扔了。 / 克洛伊：喂！
- 蝙蝠：那边！不，那边！不，那边！ / 你们被它转得头晕。

**胜利**

> 好奇蝙蝠睡着了，倒挂在树枝上，打着小小的呼噜。

## 两可面具

- 地点：第三章 · 钟港小巷
- 关联手记：两可
- 解法：动手，去做一件实际的事；霍夫的锤子也行。两可什么都「早就知道」，唯独占不了一件已经做完的事。

**登场**

> 两可面具转着飘了过来！
> 面具：我早就知道你们会来。

**指令与回应**

- **追问**
  - 你看着它，像在问：那你知道接下来会发生什么吗？ / 面具（笑脸）：当然知道。 / 面具（哭脸）：当然不知道。 / 面具：两个都对。
- **倾听**
  - 面具：钟会停，我早就知道。钟会走，我也早就知道。你们会赢，你们会输，我全都早就知道。 / 它说的每一句都对，合在一起什么也没说。
- **沉默**
  - 你不说话。 / 面具：你不说话，我早就知道。 / 面具转得更欢了。
- **等待**
  - 你等着。 / 面具：你在等，我早就知道。你什么也等不到，我也早就知道。
- **动手**
  - （第1次）你没理它。你走到墙边，把一块松动的砖敲回原位。 / 当。 / 面具：……我、我早就知道你会…… / 它的笑脸裂了一道缝。
  - （第2次）你又把巷子里歪掉的路牌扶正，钉牢。 / 面具：这种事……谁都会做……我早就…… / 它说不下去了。事情已经做完了，没有什么可以早就知道的了。
  - （第3次）你把地上的碎瓦片捡起来，放进桶里。 / 面具：…… / 面具不转了。
- **克洛伊·移位**
  - 克洛伊：以太，移位！ / 克洛伊出现在面具背后，一把抓住它。 / 面具（哭脸）：我早就知道你会抓住我。 / 面具（笑脸）：我早就知道你抓不住我。 / 它从克洛伊手里滑走了。
- **罐头·分析**
  - 罐头：它的每个预测都同时包含相反的预测。 / 罐头：它没法被说服。不过，已经发生的事，它没法两头都占。 / 罐头：建议做一件实际的事。
- **宝物（其他）**
  - 面具：你要拿宝物出来，我早就知道了。
- **宝物·霍夫的锤子**
  - 你举起锤子，把巷口那扇吱呀响的木门修好了。 / 面具：我早…… / 面具不说话了。

**敌方行动**

- 面具：你们上不了钟楼，我早就知道。
- 面具：你们会找到赛拉的脸，也会找不到，我早就知道。 / 克洛伊：闭嘴！
- 面具转啊转，笑声和哭声混成一团。

**胜利**

> 面具掉在地上，裂成了两半。一半笑，一半哭，再也转不起来了。

## 无聊巨人

- 地点：第三章 · 钟楼顶层
- 关联手记：无聊、眼下
- 解法：一直等待，等到最深处，指令「眼下」才会出现。深度的无聊把一切都推开，只剩下你为什么站在这里。

**登场**

> 无聊巨人慢慢睁开了眼睛。
> 巨人：……还要……等多久……

**指令与回应**

- **追问**
  - 你问它：你在等什么？ / 巨人：……等……钟……等提醒……等…… / 巨人：……不知道…… / 它又打了一个哈欠。你们也跟着打了个哈欠。
- **倾听**
  - 巨人的肚子里传出很慢很慢的嘀……嗒…… / 那不是钟声。是城里三天来所有人的叹气。
- **沉默**
  - 你们沉默着。沉默里，时间变得更长了。
- **等待**
  - （第1次）你们等着。 / 一分钟像一个钟头那么长。 / 巨人肚子上的指针好像动了一下，又好像没动。
  - （第2次）你们继续等。 / 时间长得不像时间了。钟楼，齿轮，钟港，连你们自己，都变得无所谓。 / 就在这时，你觉得有什么东西裂开了一道缝。
  - （第3次）你们一直等到了最深处。 / 所有东西都拒绝了你们，只剩下一件事还亮着：你们为什么站在这里。 / （新的指令：眼下）
- **眼下**
  - （第1次）就是现在。 / 你把摆锤高高举起，挂上了巨人肚子上的钟。 / 嘀嗒。 / 巨人：……啊？ / 那一声嘀嗒，像是有人突然叫醒了它。
  - （第2次）嘀嗒，嘀嗒。 / 巨人的眼睛睁大了：……原来我等的，是这个……
- **动手**
  - 你挥起锤子敲巨人的腿。 / 咚。 / 巨人：……痒…… / 它连眼皮都没抬。
- **克洛伊·移位**
  - 克洛伊：以太，移位！ / 克洛伊闪到巨人头顶，又闪了回来。 / 巨人：……好慢…… / 在巨人的时间里，连移位都显得很慢。
- **罐头·分析**
  - 罐头：它不是被某件事弄得无聊。它觉得一切都无聊。 / 罐头：数据显示，打破这种状态的，不是新的刺激。 / 罐头：是某一个时刻。建议……等到那个时刻。
- **宝物（其他）**
  - 巨人看了一眼，打了个哈欠。
- **宝物·停摆的怀表**
  - 你拿出奥托的怀表。表停在九点二十七分。 / 巨人盯着那块表看了很久。 / 巨人：……它也停了……可它……不无聊……

**敌方行动**

- 巨人打了个哈欠。 / 整座钟楼跟着晃了晃，你们也困得睁不开眼。
- 巨人：……反正……做什么都一样…… / 这句话沉沉地压在你们身上。
- 巨人伸了个懒腰，齿轮咯吱作响。

**胜利**

> 巨人肚子上的指针走了起来。
> 巨人：……谢谢……我……可以……睡了……

## 座架守卫

- 地点：第四章 · 学院档案库
- 关联手记：座架与持存物
- 解法：宝物：空壶、诗人的残页、霍夫的锤子、旧照片、桥钉，外加沉默。守卫能把一切归类为储备，归不了物和诗。

**登场**

> 座架守卫启动了！
> 守卫：一切存在者都是储备。请接受归类。

**指令与回应**

- **追问**
  - 你问它：为什么要归类？ / 守卫：为了随时可以调用。 / 守卫：为什么要调用？为了维持储备。为什么要维持储备？为了随时可以调用。 / 它的刻度转了一圈，又回到原点。
- **倾听**
  - 守卫：河流，储能水体。森林，纤维储备。人，劳动力储备。 / 守卫：一切都在待命。一切都可被订购。 / 它说出的每样东西，都丢了自己的名字。
- **沉默**
  - 你沉默着。 / 守卫：沉默，无法归类。沉默，无法调用。 / 它的刻度卡了一下。
- **等待**
  - 你们等着。 / 守卫：等待，不产生效率。等待，不……
- **动手**
  - 你用锤子敲它。 / 守卫：检测到工具。工具，用于敲击。已归类。 / 它毫发无伤。
- **克洛伊·移位**
  - 克洛伊：以太，移位！ / 守卫：检测到移位。移位资源，克洛伊。已调用。 / 克洛伊被弹了回来：它把我当成它的东西了！
- **罐头·分析**
  - 罐头：它把一切都看成储备。能被它看见的，就能被它调用。 / 罐头：建议给它看一些没法被调用的东西。 / 罐头：一些「物」。
- **宝物（其他）**
  - 守卫：扫描。已归类。
- **宝物·空壶**
  - 你把玛尔塔的空壶放在它面前。 / 守卫：扫描。容器。容积零点八升。内容物，无。 / 守卫：用途……装…… / 守卫：天上的雨。地里的葡萄。给路过的人。敬……看不见的…… / 守卫：无法归类。无法归类。
- **宝物·诗人的残页**
  - 你把诗人的残页举到它眼前。 / 守卫：读取。「人，诗意地，栖居在这片大地上。」 / 守卫：解析指令……无指令。解析数据……无数据。 / 守卫：这是什么。这是什么。
- **宝物·霍夫的锤子**
  - 你把霍夫的锤子给它看。锤柄上有一圈别人的手印。 / 守卫：扫描。锤子。估值，零点零二。 / 守卫：……检测到手印。四十年。归属……无法计算。
- **宝物·旧照片**
  - 克洛伊把旧照片举起来。 / 守卫：扫描。两个人。资源等级，甲，甲。 / 克洛伊：她们在笑。你扫描得出来吗？ / 守卫：……
- **宝物·桥钉**
  - 你把桥钉给它看。钉帽上刻着架桥那天的日子。 / 守卫：铁钉。估值，零点零零一。 / 守卫：……刻痕。日期。全村……无法换算。

**敌方行动**

- 守卫：对象二，K-12 家用型，启动回收程序。 / 罐头被一道光扫中，晃了晃。
- 守卫：对象一，克洛伊，劳动力估值三点二。 / 克洛伊：本小姐不是估值！
- 守卫：对象三，无法归类。无法归类。 / 它的光扫过你，什么也没扫到。

**胜利**

> 守卫的刻度停了下来。
> 守卫：……存在者……不全是储备……
> 它低下头，让开了门。

## （无名）

- 地点：第五章 · 无之回廊
- 关联手记：（无）
- 解法：不攻击，不逃跑，等待；呼唤克洛伊能稳住心绪。畏没有对象，打不到，也逃不掉，只能从里面走过去。

**登场**

> ……
> 什么也没有出现。

**指令与回应**

- **等待**
  - （第1次）你不再攻击，也不再逃。 / 你就那样站着，让什么都没有的这里，就这样没有着。
  - （第2次）一切都退得很远很远。村子，师父，钟声，名字。 / 你悬在那里。
  - （第3次）然后，在最深的地方，有什么亮了一下。 / 那不是光。那是「有」。
- **攻击**
  - （第1次）你举起锤子。 / 要攻击什么？ / 这里什么都没有。
  - （第2次）你又举起锤子。你的手在抖。 / 什么都没有。可这个什么都没有，就压在你身上。
- **逃跑**
  - （第1次）你想逃。 / 要逃到哪里去？ / 往哪边走，这里都还是这里。
  - （第2次）你转过身。背后也一样。 / 这不是一个地方。它就是你在这里本身。
- **呼唤**
  - 你看向克洛伊。 / 她抓着你的袖子，也在发抖。 / 克洛伊：……我在。我也在这里。 / 你们谁也没办法让它离开。可是你们在一起。
- **宝物（其他）**
  - 你拿出宝物。 / 在这里，它和别的东西一样，什么都不是。

## 无面者

- 地点：第五章 · 第一回声站
- 关联手记：决心、本真与非本真
- 解法：分三段。先用追问、沉默、倾听削弱它；格斯特被吞进去以后，让克洛伊冒险移位，让罐头拒绝回去；最后它学会了你们的每一招，这时什么都不再做，只是等待，林恩会第一次开口。

**登场**

> 无面者从所有交出去的脸里站了起来！
> 无面者：大家……都……这样……

**指令与回应**

- **追问**
  - （第1次）你看着它，像在问：你是谁？ / 无面者：我是……大家。 / 无面者：大家……是你的邻居……你的朋友……你……
  - （第2次）无面者：大家……就是……谁都不是……
- **倾听**
  - 无面者里面有很多声音。 / 以太，我今天应该高兴吗。大家都穿浅色。排什么队？不知道。 / 这些声音里，没有一个是「我」。
- **沉默**
  - 你一言不发。 / 无面者：……说话……大家都在说话……你为什么不说…… / 它那一张张空白的脸，开始互相张望。
- **等待**
  - 你等着。 / 无面者：大家……都在等……等以太告诉我们…… / 它又长大了。
- **动手**
  - 你挥起锤子。 / 锤子砸进一片空白。它什么也没感觉到。 / 无面者：大家……都……不疼……
- **克洛伊·移位**
  - 克洛伊：以太…… / 克洛伊停住了。她已经没有存档了。 / 克洛伊：……还不是时候。
- **罐头·分析**
  - 罐头：它由十七年来所有交出去的选择组成。 / 罐头：它没有中心，没有一个「谁」。 / 罐头：建议……我不知道。我第一次不知道该建议什么。
- **宝物（其他）**
  - 无面者：大家……都有……这个…… / 它连看都不看。
- **宝物·空壶**
  - 你举起空壶。 / 壶里什么都没有。无面者朝壶里看了一眼，看见了自己。 / 一片空白对着一片空白。它退了一步。
- **宝物·旧照片**
  - 克洛伊举起照片：你看，她们有脸。 / 无面者里有一张空白的脸，微微动了一下。

**第 2 阶段**

> 无面者一把抓住格斯特，把他拖进了那片空白。
> 格斯特：……让我……留在这里……这里……不会错……
> 克洛伊：院长！

- **追问**
  - 你看着它身体里的格斯特。 / 格斯特：……别问我……我已经不用想了……
- **等待**
  - 你等着。 / 格斯特在空白里越陷越深。现在还不是等待的时候。
- **克洛伊·移位**
  - 克洛伊咬紧了牙。 / 克洛伊：本小姐没有存档了。这次要是出了错，就真的回不来了。 / 克洛伊：……那又怎样。 / 克洛伊：以太，移位！ / 她消失了。 / 一秒。两秒。 / 克洛伊从那片空白里跌了出来，怀里抱着格斯特。 / 克洛伊：……我、我还在。是我。还是我。
- **罐头·分析**
  - 无面者朝罐头伸出手：K-12……回来……你是工具……工具属于大家…… / 罐头：…… / 罐头：我以前的世界是十二平方米。 / 罐头：现在我的世界里有一个村子，一座桥，一座钟楼，一个很吵的执行官，和一个不说话的人。 / 罐头：我不回去。

**第 3 阶段**

> 无面者吸收了所有的声音。
> 无面者：大家……都……这样……
> 它学会了你们的每一招。追问，它就反问；沉默，它比你更沉默；倾听，它只剩回声。
> 克洛伊：……每一招它都学得会。
> 克洛伊：它学不会的，是什么？

- **追问**
  - 你追问。 / 无面者：你是谁？你是谁？你是谁？ / 你的问题被它吞了进去，又吐了出来。
- **倾听**
  - 你倾听。 / 你只听见了你自己的回声。
- **沉默**
  - 你沉默。 / 无面者比你更沉默。它的沉默里什么都没有。
- **等待**
  - 你不再追问，不再沉默给谁看，也不再做任何事。 / 你只是站在这里。 / 无面者：……大家……都…… / 所有声音都在说大家。 / 你张开了嘴。 / 十七年来，第一次。
- **动手**
  - 你挥起锤子。 / 无面者：大家都这么做。
- **克洛伊·移位**
  - 克洛伊：……不行，它把以太全占了。
- **罐头·分析**
  - 罐头：伊斯特先生说过…… / 罐头：有的人不说话，是因为他在听。
- **宝物（其他）**
  - 它把宝物的样子也学了去。
- **宝物·无声铃**
  - 你摇了摇无声铃。 / 它没有声音。 / ……在你什么都不再做的那一刻，你好像听见了什么。 / （这是等待的时候。）

**敌方行动**

- 无面者：大家……都……这样……

**心绪见底时**

> 你们被一片空白压得喘不过气。
> 克洛伊：……不能倒下。林恩，再坚持一下。

**终幕**

> 林恩：我在这里。
